Where can I find the key?

Run python -m bridge_x key in the same environment used to start Bridge X. With --ui, the personal file is normally %LOCALAPPDATA%\BridgeX\local.key on Windows. BRIDGEX_DATA_DIR changes its directory; an explicit BRIDGEX_LOCAL_KEY takes precedence. The browser keeps the key only in this tab’s memory.
